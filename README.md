Aplicativo Minhas Finanças

Aplicativo desenvolvido em Flutter para auxiliar no controle de despesas pessoais.

Funcionalidades

Cadastro de despesas com descrição e valor.

Registro automático da data.

Cálculo do total das despesas.

Exclusão de despesas por meio de deslize.

Armazenamento local dos registros.

Tecnologias utilizadas

Flutter

Dart

Shared Preferences

JSON

Como executar

Instale o Flutter.

Baixe ou clone este repositório.

Execute flutter pub get.

Inicie um emulador ou conecte um dispositivo.

Execute flutter run.

Documentação

O projeto inclui um documento com a análise técnica do código, as bibliotecas utilizadas, os recursos necessários e os testes recomendados.
